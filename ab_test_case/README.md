# Кейс: A/B-тест упрощения формы регистрации на лендинге курса

1. Проблема

Лендинг курса конвертирует посетителей в регистрацию на уровне 18%. Продуктовая гипотеза: форма регистрации (5 полей: имя, email, телефон, город, источник) слишком длинная и отсеивает часть заинтересованных пользователей.

2. Гипотеза

**Если** сократить форму регистрации до 2 обязательных полей (email + имя), **то** конверсия в регистрацию вырастет, **потому что** снизится когнитивная нагрузка и трение на этапе первого контакта с продуктом.

3. Дизайн эксперимента

| Параметр | Значение | Обоснование |
|---|---|---|
| Метрика успеха | % посетителей лендинга → зарегистрировался | Основная метрика верхней воронки |
| Baseline conversion | 18.0% | Средняя конверсия за последние 4 недели |
| Minimum Detectable Effect | +3 п.п. (до 21%) | Минимальный прирост, который имеет смысл для бизнеса |
| Alpha / Power | 0.05 / 0.80 | Стандартные пороги |
| Требуемый размер выборки | 2 737 на группу (5 474 всего) | Расчёт по формуле для двух пропорций — см. `ab_test_analysis.py`, часть 1 |
| Длительность теста | ~12 дней при трафике 450/день, округлено до 2 полных недель | Чтобы захватить недельную сезонность (будни/выходные) |
| Единица рандомизации | user_id (cookie для незалогиненных) | Избегаем cross-contamination одного пользователя между группами |

**Что проверяли до запуска:**
- Sample Ratio Mismatch (SRM) — сплит должен быть честным 50/50, иначе результат недостоверен независимо от p-value.
- Отсутствие пересечения с другими одновременно идущими экспериментами на той же метрике.

4. Результаты

| Группа | N | Конверсия | 95% CI (Wilson) |
|---|---|---|---|
| Control (старая форма) | 2 750 | 18.07% | [16.68%, 19.56%] |
| Treatment (короткая форма) | 2 742 | 21.37% | [19.88%, 22.95%] |

- Z-статистика = 3.07, **p-value = 0.0021** — значимо на уровне 5%.
- Относительный прирост конверсии: **+18.3%**.
- SRM-check: p = 0.914 — сплит корректный, оснований не доверять результату нет.
- Доверительные интервалы групп не пересекаются — эффект устойчив, а не эффект флуктуации на границе значимости.

5. Решение

**Раскатать короткую форму на 100% трафика.** Дополнительно:
- Замерить, не просело ли качество лидов (source attribution, follow-up conversion в оплату курса) — короткая форма могла привлечь менее "квалифицированный" трафик, это отдельная метрика для мониторинга после раскатки.
- Через 4-6 недель после полной раскатки проверить, не откатилась ли метрика (эффект новизны/novelty effect).

Частые ошибки, которых тест избежал (и на что смотреть в реальной работе)

- **Peeking** — не останавливали тест раньше расчётного срока при первых признаках значимости; тест шёл полный запланированный период на полном требуемом объёме выборки.
- **Sample Ratio Mismatch** — проверили баланс сплита перед тем, как доверять результату.
- **Путаница относительного и абсолютного прироста** — в отчёте явно разделены "+3.3 п.п. абсолютно" и "+18.3% относительно" (это разные числа, и их подмена — частая ошибка в презентации результатов).
