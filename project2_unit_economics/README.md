# Проект 2: Unit Economics + сценарный P&L (EdTech Subscription)

**Тип:** финансовое моделирование в Excel — LTV/CAC по каналам, сценарный прогноз P&L
**Связь с проектом 1:** retention-кривая и completion rate по каналам взяты напрямую из SQL-анализа проекта 1 — модель показывает, как продуктовая аналитика превращается в финансовые метрики.

## Файл

`unit_economics_model.xlsx` — 4 листа:

1. **Assumptions** — все входные допущения (синим): средний чек, маржа, CAC по каналам, темп роста базы, операционные расходы. Меняешь синюю ячейку — модель пересчитывается.
2. **Cohort_LTV** — расчёт маржинального LTV на основе понедельной retention-кривой (данные из проекта 1).
3. **Unit_Economics** — LTV/CAC и payback period по каждому каналу привлечения, с автоматическим вердиктом ("здоровая экономика" / "убыточный канал").
4. **Scenario_PnL** — 12-месячный прогноз базы подписчиков, выручки и EBITDA в трёх сценариях (Base / Optimistic / Pessimistic).

## Ключевые находки модели

- **Organic** — единственный канал с LTV/CAC ≥ 3x (здоровая unit-экономика за счёт почти нулевого CAC), несмотря на средний completion rate.
- **Paid ads** и **social media** убыточны по unit-экономике (LTV/CAC < 1x) даже при пересчёте на реальный CAC — это количественно подтверждает вывод проекта 1 о низком качестве этих каналов.
- **Corporate** и **partner referral** — приемлемая экономика, но не оптимальная: высокий completion rate компенсируется более высоким CAC (особенно у corporate).
- Base-сценарий даёт ~$649K маржинальной выручки и ~$433K EBITDA за 12 месяцев при консервативном темпе роста базы 4%/мес.

## Почему это в портфолио

Показывает связку "аналитика данных → финансовые метрики → решение о распределении бюджета" — то есть способность довести SQL/Python-анализ до языка, на котором говорит бизнес (LTV, CAC, EBITDA), что напрямую опирается на твой существующий опыт финансового моделирования.
