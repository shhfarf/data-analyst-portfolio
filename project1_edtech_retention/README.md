#Проект 1: EdTech — анализ оттока и вовлечённостия

Бизнес-задача

Платформа теряет значительную часть участников курса до его завершения. Нужно понять:
1. На каких неделях курса происходит наибольший отток и стабилизируется ли retention к концу.
2. Какие каналы привлечения дают более "качественных" (устойчиво вовлечённых) участников.
3. Достаточно ли эти различия значимы, чтобы менять распределение бюджета/приоритеты.

Структура проекта

| Файл | Назначение |
|---|---|
| `generate_data.py` | Датасет (users, engagement) |
| `sql_queries.sql` | 5 SQL-запросов: когортный retention, funnel drop-off (LAG), ранжирование каналов (RANK), RFM-подобная сегментация (NTILE), оконные агрегаты |
| `run_sql.py` | Выполнение запросов через SQLite, экспорт результатов в `data/result_*.csv` |
| `eda_analysis.py` | EDA + статистические тесты (chi-square, Welch t-test), построение графиков |
| `dashboard.html` + `dashboard_data.json` | Интерактивный дашборд (Chart.js) — открыть в браузере |
| `charts/` | Статичные графики (retention curves, completion by channel) |

Ключевые находки

- Retention: медианная когорта теряет ~55% участников к неделе 6 и выходит на плато ~32-35% к неделе 12. Самое резкое падение — недели 1-4 (около 9-10% оттока еженедельно).
- Каналы привлечения значимо различаются по completion rate: `corporate` (58.9%) и `partner_referral` (49.5%) сильно опережают `paid_ads` (25.2%) и `social_media` (23.1%). Chi-square подтверждает значимость связи (χ²=427.97, p < 0.001).
- Вовлечённость (events/неделю) у пользователей из `corporate` статистически значимо выше, чем у `paid_ads` (Welch t-test, p < 0.001) — не только выше конверсия в завершение, но и выше активность на всём протяжении курса.

Рекомендации бизнесу

1. Пересмотреть распределение бюджета привлечения в пользу `corporate`/`partner_referral`-подобных каналов — они дают устойчиво более вовлечённую аудиторию.
2. Сфокусировать retention-мероприятия (напоминания, менторская поддержка) на неделях 1-4, где происходит основной отток.
3. Для `paid_ads`/`social_media` — пересмотреть onboarding: возможно, проблема не в качестве трафика, а в первом впечатлении от продукта.

Как запустить

```bash
python3 data.py          data/users.csv, data/engagement.csv
python3 run_sql.py         выполняет SQL, сохраняет data/result_*.csv
python3 eda_analysis.py    EDA, статтесты, графики в charts/
затем открыть dashboard.html в браузере
```
